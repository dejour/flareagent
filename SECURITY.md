# Security policy

FlareAgent can access private GitHub repositories and run code in Cloudflare Sandboxes. Please do not report vulnerabilities with working exploits or credentials in public issues.

Report security issues privately through GitHub's **Report a vulnerability** feature on this repository. Include the affected version or commit, reproduction steps, and impact. We will acknowledge the report and coordinate a fix before public disclosure.

If a credential may have leaked, revoke or rotate it with its provider immediately. Do not send the credential in the report.
